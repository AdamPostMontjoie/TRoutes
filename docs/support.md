# T Routes Support

For help with T Routes, email [adampostmontjoie@gmail.com](mailto:adampostmontjoie@gmail.com).

When reporting a problem, please include:

- What you were trying to do.
- What happened instead.
- Your iPhone model and iOS version.
- A screenshot, when useful.

Do not include your MBTA API key in a support email.

## Common Questions

### Why does T Routes request location access?

Location is used to find nearby stops and update progress during active journeys. Location-dependent features can be disabled by revoking access in iOS Settings.

### Why does the Stops tab request an MBTA API key?

Routes works without an API key using the MBTA's lower anonymous request limit. The Stops tab checks arrivals for multiple stops and requires the higher request limit available with a free MBTA developer key.

### How do I remove my information?

Routes, stops, pins, preferences, journey state, and the optional API key are stored locally. Delete individual items in the app, remove the API key in Settings, or uninstall T Routes to remove its local app data.
