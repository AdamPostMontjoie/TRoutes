1. Top bar on  nearby stops tab. This would filter the list of nearby stops.

All | Subway | Bus | Rail | (Refresh Icon)

- All: All stops sorted by distance
- Subway: Subway stops sorted by distance (RL, GL, BL, OL, Mattapan line)
- Bus: Bus stops sorted by distance (Regular Bus, silver line)
- Rail: Rail stops sorted by distance (Commuter Rail)

Refresh Icon would just request current coordinates and use those to refresh the List

2. Timer

Right now, the time refreshes on appear, never any other time. we need to fix this to avoid scrolling destroying API limit

What should happen (I think)
- We need a 15 second timer tracker for every single banner on our screen (2 on stops in both directions)
- The only time we need to call the API is if 
A. The banner is on screen
B. The timer is at or past 15 seconds

All stops will initially be in need of an API call
When we swipe directions, we want to make a call, but if we swipe and swipe back within before 15 seconds, we will have the cached times and just display those

So for each banner
- a timer for each directions
- a place for cached times for each direction
